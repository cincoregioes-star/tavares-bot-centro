Converse com o GPT aqui

A conversa fica nesta página. Para responder usando a sua conta do ChatGPT, o Codex precisa estar instalado, autenticado e conectado pelo programa local do TAVARES Bot. Não é necessária uma chave de API paga. A integração utiliza a cota do plano ChatGPT.

Conexão

Procurando conexão local...

O código criado ficará em uma pasta separada no seu computador: projetos-locais/nome-do-projeto.

O modo Desenvolver permite editar arquivos da pasta do projeto, mas não publica no GitHub.

Primeiro acesso no Windows
1. Instale o Node.js LTS e o Codex CLI.
2. Execute codex login e escolha entrar com ChatGPT.
3. Inicie o arquivo INICIAR-TAVARES-GPT.bat do pacote local.
4. Abra esta página pelo endereço local iniciado pelo programa.

Importante: apenas abrir o GitHub Pages não ativa o GPT. A ponte deve estar rodando neste computador.

Conversa com o desenvolvedor

Descreva uma ideia, peça explicações ou solicite que o Codex desenvolva o seu projeto. Para criar arquivos, escolha o modo Desenvolver antes de enviar.
Como abrir os arquivos?

Após desenvolver, abra o HTML gerado na pasta projetos-locais do pacote local. Para acompanhar ou continuar, selecione a mesma pasta do projeto nesta tela.
