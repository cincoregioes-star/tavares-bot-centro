DESENVOLVIMENTO ASSISTIDO POR IA

Peça um sistema. Acompanhe. Revise.

Descreva a aplicação que você quer criar ou aprimorar. O agente pode produzir arquivos HTML, CSS e JavaScript diferentes para cada ideia, em vez de repetir um modelo genérico. Os pedidos passam pelo GitHub e retornam como uma proposta de código para aprovação.

1. Descreva a ideia

O botão abre a criação de uma issue com sua descrição preenchida. Você precisará estar conectado ao GitHub e confirmar o envio lá. Depois, o GitHub Actions iniciará a geração caso a chave da API tenha sido configurada.

2. Como o agente trabalha

  1. Você escreve o pedido e cria a issue.
  2. O agente interpreta a descrição e gera código.
  3. O GitHub abre uma proposta de alterações (pull request).
  4. Você revisa o projeto e solicita ajustes, se necessário.
  5. Só depois da aprovação o código poderá ser incorporado ao site.
Para revisar, abra a issue original e escreva um comentário começando por /ajustar.

Exemplo: /ajustar acrescente gráficos e melhore a visualização no celular

3. Configuração necessária

A IA só executará após configurar a chave. O ChatGPT Plus não inclui créditos de API. O uso da API pode gerar cobranças por processamento.

No GitHub: repositório → Settings → Secrets and variables → Actions → New repository secret → nome OPENAI_API_KEY. Cole sua própria chave diretamente no GitHub. Nunca envie a chave pelo chat nem coloque no código do site.

Configurar segredo no GitHub ↗

Modelo padrão da integração: GPT-5 mini, sujeito à disponibilidade e aos preços do provedor. Os projetos gerados precisam de testes antes de uso em produção.
